NGXBAOIOS STORE — HƯỚNG DẪN
================================

Cấu trúc:
- index.html
- assets/css/base.css     (CSS giao diện gốc được tách ra)
- assets/css/polish.css   (CSS chỉnh font, căn lề, khoảng cách, responsive)

Cách dùng:
1. Giữ nguyên cấu trúc thư mục khi tải lên GitHub/Vercel.
2. Đặt index.html ở thư mục gốc của website.
3. Đảm bảo thư mục assets/css/ nằm cùng cấp với index.html.
4. Các file nhạc MP3 hiện vẫn được tham chiếu bằng tên file tương đối trong index.html;
   hãy đặt các file MP3 cùng thư mục với index.html hoặc sửa đường dẫn nếu bạn lưu ở nơi khác.

Lưu ý:
- Nội dung sản phẩm và JavaScript hiện có được giữ nguyên.
- CSS mới chỉ tinh chỉnh kiểu chữ, khoảng cách, chiều cao nút, căn đều thẻ sản phẩm
  và bố cục trên màn hình nhỏ.

Hiệu ứng CSS bổ sung: card nhấc nhẹ khi rê chuột, ảnh phóng to nhẹ, nút có ánh sáng lướt, nền glow tím/xanh dịu, focus rõ ràng và hỗ trợ giảm chuyển động.


Gói hiệu ứng neon gaming bổ sung:
- Màn hình loading ngắn khi mở trang.
- Thanh tiến trình cuộn ở mép trên.
- Nút hỗ trợ Zalo nổi ở góc trái dưới.
- Viền neon/kính mờ, hiệu ứng mở modal và tối ưu các nút nổi trên mobile.


BẢN TRANG TRÍ TOÀN WEBSITE — NEON GAMING
- Thêm assets/css/showcase.css làm lớp giao diện cuối cùng.
- Nâng cấp header, hero, thẻ sản phẩm, thanh tìm kiếm, dịch vụ, cam kết, FAQ, liên hệ, modal, vòng quay may mắn và trình phát nhạc mini.
- Có hiệu ứng xuất hiện khi cuộn, ánh sáng nhẹ theo con trỏ trên máy tính, nút lên đầu trang và tối ưu responsive.
- Giữ nguyên nội dung sản phẩm, danh sách nhạc và logic quay hiện có. Các file MP3 vẫn cần đặt đúng đường dẫn như trong HTML.
